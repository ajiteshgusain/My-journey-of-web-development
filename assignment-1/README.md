# Ajitesh's First-Semester section a course-robotics and ai Assignment Web Development Portfolio

This repository contains a single-page portfolio website and supplementary files built to demonstrate fundamental skills in **HTML5** and **Basic CSS (focusing on the Box Model)**.

The project fulfills several requirements from my first-semester web development curriculum, including semantic structure, table creation, form handling, and applying basic styling.

## 🚀 Project Goal & Purpose

The main goals of this project are:
1.  To create a **personal, one-page portfolio** showcasing bio, skills, and contact details.
2.  To demonstrate practical use of core HTML elements, including **tables**, **ordered/unordered lists**, and **forms with various input types**.
3.  To apply basic **CSS principles (specifically Margin and Padding)** to control layout and enhance readability.

## 📁 Project Structure

The project is designed to be minimal and easy to navigate.
